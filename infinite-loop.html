What is an Infinite Loop?

An infinite loop is a loop that never stops running. Your program gets stuck repeating the same instructions forever. When Svinesti detects that your code has been running for too long (more than one second — an eternity in computer time), it assumes you have an infinite loop and stops your program. This doesn't normally happen automatically, so it's a good idea to learn how to avoid it!

Loops repeat code while a condition is true. An infinite loop happens when that condition never becomes false. This usually happens because you forgot to change something inside the loop, or because the condition is faulty and can never become true.

Here's a common infinite loop. Can you spot the problem?

Python
# Goal: move forward 5 times
count = 0
while count < 5:
    move()
Java
// Goal: move forward 5 times
int count = 0;
while (count < 5) {
    move();
}

We forgot to increase count inside the loop! It stays zero forever, so it will always be less than five. Adding count = count + 1 inside the loop fixes the code.

Here is another example:

Python
while isRed():
    turnLeft()
Java
while (isRed()) {
    turnLeft();
}

The pig spins forever if the current square is red. The examples above are obviously wrong, but as your program grows bigger, they can be easy to miss. Also, some infinite loops are more sneaky, like the next one.

Python
# Goal: stop when count is 0 or 5
count = 3
while count != 0 or count != 5:
    move()
    count = count + 1
Java
// Goal: stop when count is 0 or 5
int count = 3;
while (count != 0 || count != 5) {
    move();
    count = count + 1;
}

Simple! "While count isn't zero or five, continue". Right? Right?! The computer takes everything literally: if either count isn't zero, or count isn't five, continue. If count is zero it can't be five, and vice versa, so one of the two conditions will always be satisfied. This condition literally can not be false. The correct condition is:

Python
# Goal: stop when count is 0 or 5
count = 3
while count != 0 and count != 5:
    move()
    count = count + 1
Java
// Goal: stop when count is 0 or 5
int count = 3;
while (count != 0 && count != 5) {
    move();
    count = count + 1;
}

This condition is false when count reaches five, because the "and" needs both comparisons to be true at the same time.

So, when your code runs for too long, check these things:

  1. Does something change inside your while loop?
  2. Will that change eventually make the condition false?
  3. Are you trying to escape a color by turning? (Spoiler: that won't work)

Happy coding!
