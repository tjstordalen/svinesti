    About
    
                    
    Svinesti is an educational programming game. Guide the pig to collect all the apples.
    

                    
    Goal
    
                    
      
                        
    • Red, green, and blue tiles are safe
      • 
                        
    • Avoid empty/white tiles (game ends!)
      • 
                        
    • Collect all apples to win
      • 
                    
    

                    
    Available Functions
    
                    
    move()       # Move forward
turnLeft()   # Turn 90° left
turnRight()  # Turn 90° right

# Check tile color (returns true/false)
isRed()
isGreen()
isBlue()
    
                
    

                
    
                    
    Languages
    

                    
    Python
    
                    
    Full Python 3 supported
    
                    
    for i in range(4):
    move()
    if isRed():
        turnLeft()
    

                    
    Java
    
                    
    Minimal Java-like syntax
    
                    
    Types: int, boolean
    
                    
    Control: if/else, while, { } blocks
    
                    
    Operators: +, -, *, /, %, <, >, ==, !=, &&, ||, !
    

                    
    int count = 0;
while (count < 4) {
    move();
    if (isRed()) {
        turnLeft();
    }
    count = count + 1;
}
    
                    
    Limitations: No arrays, strings, classes, or for loops
    
                
    

                
    
				
                    
    Keyboard Shortcuts
    
                    
      
                        
    • Ctrl + Enter - Run code
      • 
                        
    • ? - Open/Close this help
      • 
                    
    
                    
    Level Editor
    
                    
    Click Edit in the header to create custom levels.
    
                    
      
                        
    • Left-click tile: cycle colors
      • 
                        
    • Right-click tile: toggle apple
      • 
                        
    • Drag pig: move starting position
      • 
                        
    • Click pig: rotate direction
      • 
                        
    • Use +/− buttons to resize
