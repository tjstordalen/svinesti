What is an Infinite Loop?

An infinite loop is a loop that never stops running. Your program gets stuck repeating the same instructions forever, like a dog chasing its own tail — except less cute and more frustrating.

When Svinesti detects that your code has been running for too long (more than 1 second — an eternity in computer time), it assumes you have an infinite loop and stops your program. Otherwise your browser would freeze, and nobody wants that.

How Does an Infinite Loop Happen?

Loops repeat code while a condition is true. An infinite loop happens when that condition never becomes false. It's like asking "are we there yet?" when you're walking in circles.

This usually happens because:

  • You forgot to change something inside the loop
  • The condition can never be satisfied
  • Your pig is spinning in place like a confused ballerina

Example: The Classic Mistake

Here's a common infinite loop. Can you spot the problem? 

# Goal: move forward 5 times
count = 0
while count < 5:
    move()
    # Oops! We forgot to increase count!
// Goal: move forward 5 times
int count = 0;
while (count < 5) {
    move();
    // Oops! We forgot to increase count!
}
The Problem
count starts at 0 and never changes. Since 0 is always less than 5, the loop runs forever! The pig moves until it falls off the edge of the world (or hits a wall, or we stop it).

The Fix

Make sure something changes inside your loop that will eventually make the condition false: 

# Goal: move forward 5 times
count = 0
while count < 5:
    move()
    count = count + 1  # Now count increases!
// Goal: move forward 5 times
int count = 0;
while (count < 5) {
    move();
    count = count + 1;  // Now count increases!
}
Now it works!
count goes 0, 1, 2, 3, 4, 5. When it reaches 5, the condition count < 5 becomes false, and the loop stops. The pig moves exactly 5 times. Victory!

Another Example: The Spinning Pig

This one's sneaky. The pig just... spins. Forever. Like a very committed breakdancer. 

# Goal: turn until we're NOT on a red tile
while isRed():
    turnLeft()
# But wait... turning doesn't change what tile we're on!
# The pig just spins in place forever.
// Goal: turn until we're NOT on a red tile
while (isRed()) {
    turnLeft();
}
// But wait... turning doesn't change what tile we're on!
// The pig just spins in place forever.
The Problem
turnLeft() changes which way the pig is facing, but it doesn't move the pig to a different tile. If the pig starts on a red tile, it will always be on a red tile, no matter how much it turns. Dizzy pig, infinite loop.
Tip
Before writing a loop, ask yourself: "What will make this loop stop?" If you can't answer that question, you might be about to write an infinite loop. Your pig will thank you for thinking ahead.

Quick Checklist

When your code times out, check these things:

  1. Does something change inside your while loop?
  2. Will that change eventually make the condition false?
  3. Are you trying to escape a color by turning? (Spoiler: that won't work)
  4. Did you accidentally create a pig tornado?
